# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-05-07

- Established the standalone AI-Driven Market Digital Twin Platform package.
- Added the six-tab Streamlit product interface: Command Center, Digital Twin Workflow, Agent Reasoning, Portfolio Lab, Risk & Governance, and Explainability & Audit.
- Added the original end-to-end research workflow with market data validation, structured reasoning, market graph features, portfolio simulation, fusion allocation, risk governance, and audit export.
- Added provider-aware LLM configuration for OpenAI, Anthropic, Google, and offline workflow reasoning.
- Added the sidebar Platform Assistant with independent hosted-LLM settings, multi-conversation support, message deletion, question modification, and regeneration.
- Added smoke and unit tests covering the complete workflow, LLM registry, assistant behavior, privacy guarantees, and offline execution.
