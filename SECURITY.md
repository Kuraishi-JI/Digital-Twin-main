# Security Policy

## Supported Versions

The current platform release line is `0.1.x`.

## Reporting Issues

Please report security issues privately to the maintainers before opening a public issue.

Do not include private API keys, uploaded customer data, brokerage credentials, or proprietary portfolios in issue reports.

## Scope

This project is a local research and decision-support platform. It does not execute trades and should not be connected to brokerage systems without a separate security review.
