# Offline Workflow Walkthrough

1. Start the app.

```bash
python -m streamlit run app.py
```

2. Keep sample market data enabled in the Command Center.
3. Choose a universe such as `SPY`, `QQQ`, `TLT`, `GLD`, `XLE`, and `XLV`.
4. Select the `Balanced` risk profile.
5. Run the workflow.
6. Review the tabs from left to right.
7. In `Risk & Governance`, add an override note and record the human review decision.
8. In `Explainability & Audit`, download the markdown report.
